Projekt F: Datensicherung & Wiederherstellung

Proxmox Backups + 3-2-1 Prinzip + External SSD (in Vorbereitung)

1. Ziel

  • Regelmäßige, automatisierte Backups von VMs/CTs (Proxmox)
  • Backup-Ziel: externe SSD (lokal) + optional Offsite (später)
  • Wiederherstellbarkeit testen (Restore-Drill)

2. Ist-/Soll

  • Ist: Erste Proxmox-Setups, Snapshots vorhanden, aber kein Backup-Standard
  • Soll: Verlässliche Backups nach 3-2-1, mit regelmäßigem Restore-Test

3. Geplante Architektur

  • Primary: Proxmox VE (Host)
  • Backup Target: Externe SSD (mount + Proxmox storage)
  • Optional: Offsite-Kopie (später: rsync/Cloud/S3-compat)

4. Nächste Schritte

  1. SSD anschließen, Gerät identifizieren (lsblk)
  2. Filesystem + Mountpoint (z. B. /mnt/backup-ssd)
  3. Proxmox Storage hinzufügen (Directory)
  4. Backup Job planen (Schedule)
  5. Restore-Test dokumentieren (Screenshot + Logs)

5. Nachweise (werden ergänzt)

  • Proxmox Storage-Konfiguration (Screenshot)
  • Backup Job (Screenshot)
  • Backup-Log (TASK OK)
  • Restore-Job (TASK OK)
