Projekt E: Infrastruktur-Monitoring

Prometheus + Grafana + node-exporter + cAdvisor

1. Ziel

  • Host- und Container-Metriken transparent überwachen (CPU/RAM/Disk/Netzwerk)
  • Nachweis über Prometheus Targets (UP), Grafana Dashboard und cAdvisor Übersicht

2. Projektumgebung

  • Plattform: Proxmox VE → Ubuntu Server VM (ubuntu-server-01 / 192.168.178.40)
  • Stack: Docker + Docker Compose
  • Services/Ports: Grafana (3000), Prometheus (9090), cAdvisor (8081→8080)
  • Exporter: node-exporter (Host), cAdvisor (Container)

3. Architektur

  • Prometheus sammelt Metriken (Scraping von Exportern)
  • Grafana visualisiert die Metriken über Dashboards
  • cAdvisor liefert Container-/cgroup-Metriken

4. Verifikation (Nachweise)

  • docker compose ps: Services laufen
  • /targets: Targets sind UP
  • Grafana: Dashboard zeigt Metriken
  • cAdvisor: Container-Übersicht erreichbar
